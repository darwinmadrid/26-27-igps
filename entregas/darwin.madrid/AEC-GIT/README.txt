Actividad AEC-GIT
Alumno: Darwin Madrid

En esta actividad he practicado el movimientos básicos en git
Pasos realizados:
1. Hice un fork del repositorio del docente en mi cuenta de GitHub.
2. Cloné mi fork en mi ordenador con git clone.
3. Creé la carpeta entregas/darwin.madrid/AEC-GIT.
4. Creé el archivo README.txt y hice el primer commit "docs: nuevo archivo".
5. Subí el commit a mi fork con git push origin main.
6. Creé la rama docs/modificaciones con git checkout -b.
